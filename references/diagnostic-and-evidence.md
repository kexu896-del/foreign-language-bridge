# 诊断与证据（v1）

> 先定义任务，再收样本；先听原始录音，再看转写。一次只追一条主线。

## 一、三种无稿基线（口语）

| 样本 | 条件 | 留下的东西 |
| --- | --- | --- |
| 独白 90–120 秒 | 无稿说明一个真实经历/问题 | 原始录音 + 想传达的主旨与两个关键细节 |
| 五轮问答 | 至少一个事先未知的追问 | 录音 + 最卡的一轮 |
| 一次互动修复 | 请求重复/确认范围/换说法/总结共识 | 断点、修复动作、对方是否确认 |

记录条件：设备/麦克风、环境噪声、听众是否熟悉你、是否看提纲、是否允许重录、是否用 AI。条件不同不直接比较。

## 二、让听众复述（不看转写）

请听众只根据录音回答：

```markdown
你听到的主旨是什么：
哪两个细节最清楚：
哪里需要猜测或重听：
你接下来会问什么或做什么：
```

优先保存"对方听见了什么、要做什么"，而不是"像不像标准口音"。一次评价不是结论；尽量两位听众或换一次设备/主题。

## 三、把口音、可理解度与理解难度分开

| 概念 | 含义 | 怎么观察 |
| --- | --- | --- |
| 口音显著度 | 与听者熟悉参照的差异 | 只说明"听起来不同"，不能单独证明失败 |
| 可理解度 | 对方实际恢复了多少词语、主旨与关系 | 复述主旨/细节/数字/责任/下一步 |
| 理解难度 | 对方为理解付出的努力 | 是否重听、猜测、暂停、多次确认 |

每轮只选 1–3 个高影响问题：改变词义、时间、数字、责任或句子重点的发音/节奏/组织问题优先；只体现地区差异且不增加理解成本的，记录但不强改。

## 四、评分（0–2，仅纵向比较）

每项 `0=未完成/无证据`，`1=依赖提示或不稳定`，`2=当前条件下完成`。行为锚点与证据等级见 `rubric-anchors.md`；没有证据就记 `not_observed`，不强行给分。

| 项目 | 第 1 天 | 第 7 天 | 第 30 天 | 证据 |
| --- | ---: | ---: | ---: | --- |
| 任务与主线完成 | | | | |
| 听众恢复关键信息 | | | | |
| 理解不需持续猜测/重听 | | | | |
| 能处理陌生追问 | | | | |
| 能发现并修复断点 | | | | |
| 换听众/设备/主题后仍能完成 | | | | |

总分只用于同一个人纵向比较，不是能力等级、录用资格或人格判断。

## 五、听力基线（可选，每次循环一次）

选 30 秒–5 分钟、可合法使用的材料；首听不暂停、不看字幕，结束后立刻写：一句话主旨、三个确定细节、说话者态度/目的、不确定的时间段、我会做什么。之后按 `listening-loop.md` 修复。

## 六、延迟复测与迁移

| 时间 | 撤掉什么 | 改变什么 | 输出 |
| --- | --- | --- | --- |
| 第 1 天 | 首版后的答案 | 原条件 | 修复版 |
| 第 7 天 | 最近提示与旧句 | 平行主题/听众/设备 | 90–120 秒 + 追问 |
| 第 30 天 | 练习提示 | 真实会议/面试/电话 | 一项真实交付 |
| 第 12 周（可选） | 旧任务与旧评分 | 目标岗位/生活场景 | 完整任务 |

```markdown
7 天后仍能独立完成的：
换条件后再次失败的：
听众是否更少猜测或重听：
下一轮只改什么：
仍不能推出的结论：
```
