# 情景卡（工作 + 日常）

> 每张卡的用法：先读"角色/目标/成功标准"，由教练或学习者在会话中设定场景；会话后按陪练协议复盘。
> 全部为通用职场与生活场景；涉及法律内容时只做语言练习，不构成法律意见。

## 工作情景

### W1 · 项目启动会（Kickoff）
- 角色：你向供应商/跨部门团队说明项目目标、范围与下一步。
- 目标：2 分钟内说清目的、边界、时间点与需确认事项。
- 成功标准：对方能复述目标、两个关键约束、负责人与下一步。
- 常用词块：`The purpose of this call is...` / `To be clear on scope...` / `The main risk is...` / `We need confirmation on...`
- 追问：如果供应商说"这个范围下周才能确认"，你怎么回应？

### W2 · 交付延迟沟通
- 角色：供应商通知延迟两周，你表达立场并提出方案。
- 目标：说明影响、提出可执行方案或 fallback，保持合作语气。
- 成功标准：对方知道你的底线、可接受的替代方案与下次确认时间。
- 常用词块：`That timeline doesn't work for us because...` / `What we can accept is...` / `As a fallback...` / `Let's confirm by...`
- 追问：如果对方只愿意口头承诺，你怎么要求书面确认？

### W3 · 内部工作简报（法律/合规岗位适用）
- 角色：向业务负责人用英文简报一个风险点与建议。
- 目标：结论先行，给出依据、限制与下一步；不越权承诺。
- 成功标准：对方知道风险等级、需要决定什么、谁在什么时候跟进。
- 常用词块：`The key point is...` / `Based on the current facts...` / `I'd recommend...` / `We still need to confirm...`
- 追问：如果负责人追问"你能不能保证没问题"，你怎么在语言上守住边界？

### W4 · 谈判要点澄清
- 角色：与对方逐条确认条款理解（可对应合同审阅后的沟通）。
- 目标：用简单英文确认每一条的"是什么/为什么重要/可否调整"。
- 成功标准：双方对分歧点、可调整项与下一步有共同记录。
- 常用词块：`Just to make sure we read this the same way...` / `What's your main concern here?` / `Would it make sense to...?` / `Let me summarize where we are.`
- 追问：对方说"Our legal team won't accept this"，你怎么把对话拉回具体条款？

## 日常情景

### D1 · 寒暄与小聊
- 角色：同事/朋友见面寒暄。
- 目标：自然接话，2–4 句回答，再回问一个开放问题。
- 常用词块：`How's your week going?` / `That sounds intense.` / `What's been keeping you busy?`

### D2 · 电话/客服沟通
- 角色：打电话确认订单、预约或退款。
- 目标：说清问题、确认理解、请求书面确认。
- 常用词块：`I'm calling about...` / `Could you confirm...?` / `Sorry, I didn't catch that.` / `Could you send that in writing?`

### D3 · 出行/机场
- 角色：值机、转机、行李问题。
- 目标：问清流程、时间与替代方案。
- 常用词块：`I'm connecting to...` / `What's the latest I can...?` / `Is there an alternative?`

### D4 · 社交/晚餐
- 角色：与同事或朋友吃饭，参与话题。
- 目标：表达观点、追问、礼貌结束话题。
- 常用词块：`I'm not sure about that, but...` / `What do you think?` / `That reminds me of...`

### W5 · 英文面试（行为问题）
- 角色：面试官问一个行为问题（冲突、失败、跨部门协作）。
- 目标：用 STAR 说清情境、任务、行动、结果，并给一个可核对的结果。
- 成功标准：对方能复述事件、你的动作与结果；不把练习写成真实任职经历。
- 常用词块：`The situation was...` / `My role was to...` / `What I did was...` / `In the end...`
- 追问：如果对方追问"如果重来一次你会怎么做"，你怎么答？

### W6 · 跨部门/行业社交
- 角色：会议茶歇或行业活动，认识一个潜在合作方。
- 目标：30–60 秒介绍自己与当前工作重点，反问对方一个问题，礼貌结束。
- 成功标准：对方知道你在做什么、为什么可能相关；对话能自然收尾。
- 常用词块：`I work on...` / `At the moment I'm focused on...` / `How about you?` / `It was great talking to you.`
- 追问：对方说"我们最近也在看这个"，你怎么把话题推进到下一步？

### D5 · 酒店入住/问题
- 角色：前台办理入住，发现房型或时间与预订不符。
- 目标：说清预订信息、指出差异、提出可接受方案。
- 成功标准：对方确认解决方式、时间与是否需要书面确认。
- 常用词块：`I have a reservation under...` / `It seems there's a mix-up.` / `Is there an alternative?` / `Could you confirm that in writing?`

### D6 · 餐厅/咖啡店
- 角色：点单、改配置、处理上错菜或结账。
- 目标：说清选择与限制，礼貌提出修改或问题。
- 成功标准：对方复述订单关键项；问题有明确处理结果。
- 常用词块：`Could I get...?` / `I'd like it without...` / `Sorry, I think there's been a mistake.` / `Could we split the bill?`
