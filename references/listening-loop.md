# 听力循环（v1）

> 听力不是"听了多久"，而是声音过后能否恢复人物、时间、关系、主张与下一步。
> 与口语共用任务定义与证据原则；每轮只追一份主材料 + 一份平行材料。

## 一、先定义任务

| 任务 | 证据 |
| --- | --- |
| 抓主旨 | 一句话说出主题与走向 |
| 找细节 | 时间/数字/人物/条件，标记不确定处 |
| 追关系 | 主张、理由、转折、未解决问题 |
| 执行动作 | 按所听完成步骤或回应 |
| 进入互动 | 能回答追问，没听清时修复 |
| 迁移 | 换主题/说话者/设备/语速仍能完成 |

## 二、首听协议

选 30 秒–5 分钟、可合法使用的材料。首听通常不暂停、不看字幕；结束后立刻写：

```markdown
一句话主旨：
三个确定细节：
态度或目的：
不确定的时间段：
我会做什么：
```

不要用第二遍的答案覆盖第一遍。

## 三、六层错误地图

| 层次 | 表现 | 下一步 |
| --- | --- | --- |
| 技术/环境 | 失真、延迟、噪声、音量 | 先换设备/音源 |
| 语言未知 | 词/语法/表达没学过 | 查最小必要信息 |
| 已知没听出 | 看字幕懂，声音切不开 | 标记连读、弱读、词尾、词界 |
| 结构指向 | 词听见了，不知谁指谁 | 画句块、代词与逻辑 |
| 背景推断 | 语言可懂，缺事件/文化/专业知识 | 补一小段背景再听 |
| 注意容量 | 疲劳、信息过密 | 缩短材料、减少笔记 |

## 四、支架阶梯（可升可降）

1. 无字幕首听，写主旨与不确定段；
2. 只重听问题片段（5–20 秒）；
3. 打开英文转写核对词界与结构；
4. 只查最小信息（定义/背景），不先读整段翻译；
5. 关掉文字再听，确认声音能独立触发意思；
6. 3–7 天后不看旧笔记，用平行材料复测。

字幕是梯子，不是作弊，也不是永久依赖。真实工作里需要转写降风险就继续用，但要记录它解决了什么、撤掉后还剩什么。

## 五、五遍各司其职

1. 预测与首听（标题/场景→可能出现的人物与关系）；
2. 定位差异（首听 vs 再听，标时间段）；
3. 最小修复（只开问题片段与必要转写，写"听成什么/实际是什么/为什么"）；
4. 关闭支架再听；
5. 意义重构与行动（复述主旨与三个关系；教程就执行，会议就写交接）。

机械重放十遍，不如五遍各有问题。

## 六、听写只切关键片段

只选会改变任务结果的 5–20 秒（数字、否定、条件、责任、专名、步骤）。四列：我写下的声音 / 可靠转写 / 差异原因（未知词/没切分/弱读/词尾/注意）/ 新句复测。若每个词都对却说不出主旨，回到结构重构，不要继续拆碎。

## 七、从听见进入说出

朗读 → 延迟跟读 → 合上文本用三个关键词复述 → 改变一个事实或立场重说 → 回答材料没有的追问。跟读顺畅但复述空白，就减少模仿长度，增加关键词重构。

## 八、精听与泛听

- 精听：短、可复核、有错误地图与输出；
- 泛听：较长、主旨优先、允许漏词，材料要愿意回来。

不要把休闲观看伪装成精听；也不要把每次听歌都变作业。另选一小段进入证据循环。

## 九、14 天循环（可压缩为 7 天）

| 天 | 动作 | 证据 |
| --- | --- | --- |
| 1 | 定任务与主材料，无字幕首听 | 主旨/细节/不确定段 |
| 2 | 六层错误地图 | 1–3 个高影响障碍 |
| 3 | 最小转写修复关键片段 | 听错/原文/原因/新句 |
| 4 | 关文字意义重构 | 复述/流程/行动 |
| 5 | 高价值片段听写 + 延迟跟读 | 词界与节奏记录 |
| 6 | 回答陌生追问 | 未预先提供的输出 |
| 7 | 平行材料复测 | 与第 1 天比较 |
| 8–10 | 换说话者/主题/口音 | 熟悉度与背景变化 |
| 11 | 只修仍反复的一项 | 第三版问题片段 |
| 12 | 让 AI/同伴制造转写错误或追问 | 核验与拒绝理由 |
| 13 | 时间压力下执行/交接 | 决定、责任人、下一步 |
| 14 | 新任务收口 | 保留/降级/更换依据 |

## 十、何时算"听力在变成能力"

- 首听能保留主线，不被一个漏词打断；
- 能说清卡在声音、语言、结构、背景还是注意力；
- 只查必要片段，不用翻译覆盖整段；
- 关字幕后声音仍能触发相近意思；
- 能用自己的话重构；
- 7 天后平行材料仍能用同一方法；
- 换说话者/设备/口音后仍能完成任务；
- 没听清关键内容时会请求重复并留下书面共识。
