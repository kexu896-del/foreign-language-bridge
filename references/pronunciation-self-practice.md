# 发音自练（可选；不认证）

> 只用于自练，不做等级/发音认证；不从文字推断发音。
> 水平校准与支架见 `session-design.md` §三。

目标不是消灭口音，而是减少"改变意思"的发音问题。只在反复造成误解时练。

## 一、高影响优先

- 词尾：`work/worked`、`plan/planned`、复数 `-s`；
- 数字：`13/30`、`15/50`、`-teen/-ty`；
- 重音：`REcord/reCORD`、`PROtest/proTEST`；
- 句子重点：`We need the BLUE file.` vs `We NEED the blue file.`；
- 高频混淆：`/ɪ/-/iː/`、`/r/-/l/`、`/θ/-/ð/`（只在你的错误记录里反复出现时练）。

## 二、五步练习

1. 听辨两个词/句，写下差异；
2. 看口形、舌位、气流（可用词典音频/视频）；
3. 慢速说；
4. 放回短句；
5. 换一个陌生句再选一次。

孤立词说对、句子里消失，问题通常在节奏或调用，不在单音。

## 三、跟读五级（观察 → 生成）

1. 听并标记主旨、重音、停顿、没听清处；
2. 看文本朗读；
3. 延迟跟读（不抢速度）；
4. 合上文本，用自己的词序复述；
5. 回答材料没有的追问。

第 4 级崩塌时，缩短材料、只记三个关键词，不要无限加跟读遍数。

## 四、60 秒自检

录 60 秒独白 → 回听 → 只标一个"最可能影响理解"的点 → 做一次五步练习 → 重录 → 对比。不要一次改五个音。

## 五、边界

- 语音识别、AI 评分只能当线索，受麦克风、噪声、模型影响；
- 发音是否"通过"只能由宿主、外部测评或真人判断；
- 纯文字会话一律记 `not_observed`；
- 不追求"像母语者"，优先保证数字、时间、责任、否定与重点不被听错。
