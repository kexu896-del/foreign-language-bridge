# 会话日志与卡片（v1）

## 一、会话日志模板（每次陪练后）

```markdown
# 口语会话日志 — YYYY-MM-DD
场景：工作 / 日常 / 混合
角色与目标：
成功标准（对方要知道/做什么）：
时长与轮次：
使用的宿主与功能（语音通话/转写/安装技能）：
录音或转写位置（是否脱敏）：

## 2 个做得好的点
1.
2.

## 1 个下次焦点

## 缺口清单
### Track A（表达缺口）
- 情境与想说意思：
  卡点：
  一个可用替代表达：
  中文解释：

### Track B（形式错误，最多 1–2 条）
- 错误点（中文说明）：
  错误版本 → 正确版本：
  是否在过往记录中出现过：有记录 / 无法确认

## 互动修复
断点 / 如何发现 / 修复动作 / 对方回应 / 是否确认共识：

## 下次会话计划
下一情景 / 只练的一个点 / 复测时间：
```

## 二、缺口清单的硬规则

- Track A 每项必须有"能直接说出口的替代表达"；给不出就写"意思不清"，不编。
- Track B 只报 1–2 条，且以中文说明；不把对话变语法课。
- 复发声明（"这个错误你之前也犯过"）只有存在聊天/日志记录时才成立，否则写"无法确认是否在之前的练习中出现过"。
- 一次会话最多 1 个下次焦点；不要列 5 条"改进建议"。

## 三、Anki 卡片规则

**卡片只来自 Track A**（会说但没说出来 / 想表达但卡住）。不从 Track B 的语法错误直接做卡。

- 每张卡最多 3 个字段：**Cue**（中文提示/场景）、**Chunk**（自然英文词块）、**Example**（一个完整例句）。
- 一次最多 8 张；0–1 张也可以，宁少勿滥。
- 不写生僻词、不写整段台词、不做"单词+释义"式卡片。
- 卡片正面只给 Cue；Example 放在背面。
- 示例：

```yaml
- cue: 会上想把话题拉回重点
  chunk: Let's come back to the main point.
  example: Before we go further, let's come back to the main point.
```

## 四、复习节奏

| 时间 | 动作 |
| --- | --- |
| 当天 | 只读一遍卡片，不背 |
| 第 1 天 | 看 Cue 说 Chunk，再对照 Example |
| 第 3 天 | 遮住 Chunk，用 Example 场景重说 |
| 第 7 天 | 在陪练会话里主动用出至少 2 张卡 |
| 第 30 天 | 在真实任务/复测中检查是否还能调用 |

Anki 只负责"见得到"；能否在对话里用出来，要在陪练与复测中验证。

## 五、收口报告（每次会话结束）

```markdown
# 口语训练报告 — YYYY-MM-DD
主题 / 时长 / 难度 / 辅助模式 / 角色与任务结果：

## 具体亮点（引用原话或明确动作）
1.
2.

## 目标覆盖
| 目标表达 | 独立 | 中文提示后 | 关键词/框架后 | 模仿 | 未出现 |
| --- | --- | --- | --- | --- | --- |

## 表达复盘
- 保留（说得好的原句）：
- 修复（原句 → 更自然的说法 → 简短原因）：

## 下次重点（最多 3 条）
1.

## 下次练习（2–5 分钟迁移任务）
```

规则：

- 只引用本次真实说过的内容；没有原句就写"概述"，不编造。
- 教练示范过不等于学习者掌握；`not_observed` 不扣分。
- 纯文字会话：发音记 `not_observed`。
- 报告最多 3 条 next focus，避免"每次 10 条建议"。

## 六、掌握度标记

| 标记 | 含义 |
| --- | --- |
| `mastered` | 无本课提示、在语境中正确使用（最好不止一次或迁移到新轮次） |
| `developing` | 中文提示或轻度自我修复后正确 |
| `needs_review` | 需要英文关键词/完整范句/反复修复，或始终未用出 |
| `not_observed` | 本次没有公平机会，不评价 |

## 七、process inbox

粘贴零散表达后：

1. 只保留可复用、自然、你愿意说的；
2. 合并同义项；
3. 最多留 8 张卡；
4. 其余删掉，不建"收藏夹式"清单。

## 八、记录边界

录音、转写、日志默认私密；涉及他人声音、客户、原单位、未公开项目时：先取得同意或改用虚构材料；日志只写脱敏要点，不上传原始音频到不可控服务。
