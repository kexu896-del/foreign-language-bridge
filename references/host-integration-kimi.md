# Kimi 语音接入（v1）

> 目标：在 Kimi 中安装本技能，用语音通话做陪练，并把会话转写/要点带回证据卡。
> 现状：Kimi 支持语音通话与技能安装；"技能安装＋语音通话＋转写导出"同会话组合尚未在本机验收。首次使用按下面步骤实测并记录。
> 纯文字宿主或无语音条件：按 `basic-training-plan.md` 的"纯文字 / 无语音路径"执行；发音一律记 `not_observed`。

## 一、安装

1. 在 Kimi 的技能管理中上传/安装本技能目录（或按 Kimi 当前支持的安装方式导入）。
2. 确认技能可见，名称显示为"外语桥"或 `foreign-language-bridge`。
3. 若 Kimi 不支持目录上传，可只使用 `SKILL.md` + `coaching-protocol.md` 的核心内容作为会话提示。

## 二、同会话可行性检查（首次必做）

在同一个 Kimi 会话中依次确认：

- [ ] 技能已启用，且能说出"外语桥"定位；
- [ ] 发送 `scenario: 交付延迟沟通` 能进入角色扮演；
- [ ] 语音通话中，对方保持"一次一问、不中途纠错"；
- [ ] 通话结束后，会话里能看到可复制的转写或摘要；
- [ ] 转写能区分说话人（至少能区分教练与学习者）。

任一项不满足，记录实际表现，改用"语音通话 + 自记要点/录音"的降级方案。

## 三、推荐流程

1. 先文字确认：场景、目标、成功标准（1 分钟）；
2. 切语音通话，按 15–20 分钟结构练习；
3. 结束后回到文字：让对方输出 2 个做得好 + 1 个下次焦点 + Track A/B 清单；
4. 把转写/要点粘贴到 `session-log-and-cards.md` 的日志模板；
5. 按规则生成 ≤8 张卡片；7 天后复测。

## 四、每日听力流程

- 用户说“开始今天的训练”时，按 `daily-listening.md` 联网搜索并只发材料卡；先确认 Kimi 当前能否打开链接、识别页面播放器与日期/时长。
- 不能联网、不能打开页面或不能确认播放器时：明确说明“今天无法验证可播放材料”，按该文件第八节回退；不编造链接或用文章替代。
- 用户说“I’ve finished. Let’s talk.”后，提醒开启手机语音模式；语音不可用时改文字对话。
- 手机端可能无法写 `progress.md` / `error-log.md` / `phrase-bank.md`：输出可直接追加的 Markdown 块，并注明“未写入本地文件”。

## 五、降级方案

| 问题 | 处理 |
| --- | --- |
| 技能不可用 | 只把陪练协议作为提示词使用 |
| 转写不可导出 | 通话后自记 5 条要点；录音需先取得同意 |
| 语音延迟/听不清 | 缩短轮次；改用文字 + 录音自练 |
| 无法区分说话人 | 日志中只记"学习者说了什么"，不硬判 |
| 同会话不可行 | 分两段：语音练习 + 文字复盘（不同会话亦可） |

## 六、记录与隐私

- 记录实际宿主、版本、日期、可用/不可用项；
- 不把"安装成功"写成"语音流程验收通过"；
- 通话涉及他人或工作内容时先取得同意；客户/原单位材料一律脱敏或虚构；
- 不把宿主转写当成发音或听力认证。
